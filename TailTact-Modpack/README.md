# TailTact Survival — клиентская сборка

В этот репозиторий складываются только файлы клиентской сборки TailTact.

## Структура

- `mods/` — клиентские моды под Minecraft 26.3 + NeoForge.
- `config/` — конфиги модов.
- `resourcepacks/` — ресурспаки.
- `modpack.json` — манифест EML, который лаунчер использует для синхронизации файлов.

## Важно

Пока в папках нет реальных файлов, не подключайте `modpack.json` к публичному лаунчеру. Пустой манифест не описывает модпак и при включённой очистке может привести к удалению файлов, которыми должен управлять модпак.

## Как добавить сборку

1. Скопируйте нужные клиентские моды в `mods/`.
2. Скопируйте обязательные конфиги в `config/`.
3. Скопируйте ресурспаки в `resourcepacks/`.
4. Не добавляйте папки сервера, плагины Spigot, миры, скриншоты, логи, личные настройки и файлы аккаунтов.
5. Откройте генератор EML: https://emlproject.com/resources/modpack-json-generator
6. В поле Base URL укажите:
   `https://raw.githubusercontent.com/ВАШ_GITHUB_ЛОГИН/tailtact-modpack/main`
7. Выберите локальную папку `TailTact-Modpack` (корень, где лежат mods/config/resourcepacks).
8. Нажмите **Generate and copy JSON**. Генератор создаёт корректный `modpack.json` с путями, размерами и хешами.
9. Сохраните результат как `modpack.json` в корень этой папки.
10. Загрузите папку на GitHub в репозиторий `tailtact-modpack`.

## URL манифеста

После загрузки манифест будет доступен по адресу:

`https://raw.githubusercontent.com/ВАШ_GITHUB_ЛОГИН/tailtact-modpack/main/modpack.json`

Этот URL нужно будет вставить в TailTact Launcher → Настройки → Адрес манифеста сборки и нажать **Сохранить**, затем **Проверить манифест**.

## Обновление

Когда меняется модпак, повторно запустите EML JSON Generator и загрузите обновлённые файлы вместе с новым `modpack.json`. Игрокам не нужно вручную перекачивать моды — лаунчер проверяет manifest перед запуском.

## Ограничения GitHub

Загрузка через браузер ограничена 25 MiB на один файл. Для крупных модов используйте GitHub через командную строку (до 100 MiB на файл) либо отдельное хранилище / Git LFS, если файлы ещё крупнее.
